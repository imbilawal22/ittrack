# IT Track Institute - Advanced Typing Master 🚀

**IT Track Institute** ke liye ek modern, fast aur advanced typing speed testing website banayi gayi hai. Isme Monkeytype jaisa real-time smooth typing experience, mechanical sound effects, tactile virtual keyboard, customizable themes aur downloadable certificates shamil hain.

---

## 📁 Files & Folders Structure (Project Architecture)

```
it track lesson/
│
├── index.html              # Main HTML page (Header, modes, stats, typing area, modals)
│
├── css/
│   ├── style.css           # Core styling, responsive layout, animations, modals, print rules
│   └── themes.css          # 5 modern themes (Cyber Indigo, Matrix, Sunset, Nord, Light)
│
├── js/
│   ├── app.js              # Main typing engine, WPM/Accuracy math, caret, timer, history
│   ├── keyboard.js         # Interactive on-screen keyboard with tactile finger guidance
│   ├── sound.js            # Web Audio API mechanical switch click synthesizer (Offline)
│   └── words.js            # Word banks (Easy, Medium, Hard, Quotes, JavaScript Code)
│
└── assets/                 # Custom assets / icons (agar mazeed images add karni hon)
```

## ✨ Features (Khususiyaat)

1. **Multiple Test Modes**:
   - **Time Mode**: 15s, 30s, 60s, 120s timer countdown.
   - **Words Mode**: 10, 25, 50, 100 words test.
   - **Quotes Mode**: Famous technological and programming quotes.
   - **Code Mode**: Real JavaScript and coding syntax test.

2. **5 Modern Curated Themes**:
   - 🌌 **Cyber Indigo**: Deep slate with neon cyan and purple accents (Default).
   - 💻 **Matrix Emerald**: Hacker terminal green on obsidian black.
   - 🌅 **Sunset Coral**: Warm crimson and amber tones.
   - ❄️ **Nord Frost**: Elegant Arctic blue clean dark theme.
   - ☀️ **Executive Light**: Clean, modern professional light mode.

3. **Web Audio API Mechanical Keyboard Sounds**:
   - Pure client-side audio synthesis (no external audio files needed).
   - Switch options: *Mechanical Click*, *Thock Lubed*, *Retro Beep*, or *Mute*.

4. **Tactile Virtual Keyboard & Guidance**:
   - Full QWERTY keyboard visually on-screen.
   - Shows active keystrokes in real time.
   - Highlights the exact next letter to press (ideal for beginners and institute students).

5. **Live Performance Dashboard**:
   - Real-time **Net WPM** & **Gross WPM**.
   - Keystroke **Accuracy %**.
   - Live **Error Counter**.
   - Smooth animated progress bar.

6. **Official IT Track Institute Certificate**:
   - Student test pass karne ke baad apna naam enter karke official verified certificate generate kar sakta hai.
   - 1-Click "Print / Save PDF" option ke sath.

7. **Local History & Records**:
   - Tamam previous test results automatically browser ke `localStorage` me save hotay hain.

## 🚀 Website Kaise Chalayein (How to Run)

1. Apne computer me `it track lesson` folder kholen.
2. `index.html` file par double click karen ya kisi bhi browser (Google Chrome, Microsoft Edge, Brave, Firefox) me open karen.
3. Koi external installation ya server ki zaroorat nahi hai, yeh 100% offline aur instantly kaam karta hai!

## ⌨️ Keyboard Shortcuts

- **Start Typing**: Screen par click karein ya koi bhi key press karein.
- **Tab / Esc**: Test ko foran restart karne ke liye.
- **Space**: Next word par move karne ke liye.
- **Backspace**: Piche ja kar ghalti theek karne ke liye.
